# Ultimateday

Juego web 2D de supervivencia en un búnker postapocalíptico.

Abre `index.html` en el navegador para jugar: es un archivo único y autocontenido (imágenes incrustadas), no necesita servidor ni instalación. Las cuentas y partidas se guardan en el navegador (localStorage).

Creado por Javier (Epload) junto a Yelamo.
